# NRS 107.270 Address to which request for statement must be mailed.
If the beneficiary has more than one place of business, a request for a statement described in NRS 107.200 or 107.210 must be made to the address to which the periodic payments under the note are made. If no periodic payments are made under the note, the request must be mailed to the address of the beneficiary listed on the note or deed of trust.
