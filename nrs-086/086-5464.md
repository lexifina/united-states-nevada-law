# NRS 86.5464 Addresses of managers or managing members required; failure to file.
1. Each list required to be filed under the provisions of NRS 86.5461 to 86.5468, inclusive, must, after the name of each manager or, if there is no manager, each of its managing members listed thereon, set forth the address, either residence or business, of each manager or managing member.
2. If the addresses are not stated for each person on any list offered for filing, the Secretary of State may refuse to file the list, and the foreign limited-liability company for which the list has been offered for filing is subject to all the provisions of NRS 86.5461 to 86.5468, inclusive, relating to failure to file the list within or at the times therein specified, unless a list is subsequently submitted for filing which conforms to the provisions of this section.
