# NRS 321.339 State Land Registrar may withhold land from sale.
Notwithstanding any other provision of law, the State Land Registrar may withhold from sale any land to which the State has acquired title by any means if those lands are required for the use of any State department, agency or institution or are specifically reserved by the State for future use or sale or whenever the State Land Registrar deems that the public interest so requires.
