# NRS 459.674 "Class B firefighting foam that contains intentionally added perfluoroalkyl and polyfluoroalkyl substances" defined.
"Class B firefighting foam that contains intentionally added perfluoroalkyl and polyfluoroalkyl substances" means Class B firefighting foam containing perfluoroalkyl and polyfluoroalkyl substances that is designed to include at least one fully fluorinated carbon atom that is fully functional in the foam.
