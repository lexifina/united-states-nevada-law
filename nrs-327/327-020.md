# NRS 327.020 Names of zones.
1. As established for use in the East Zone, the Nevada Coordinate System of 1927 or the Nevada Coordinate System of 1983 must be named, and in any land description in which it is used it must be designated, the "Nevada Coordinate System of 1927, East Zone" or the "Nevada Coordinate System of 1983, East Zone."
2. As established for use in the Central Zone, the Nevada Coordinate System of 1927, or the Nevada Coordinate System of 1983 must be named, and in any land description in which it is used it must be designated, the "Nevada Coordinate System of 1927, Central Zone" or the "Nevada Coordinate System of 1983, Central Zone."
3. As established for use in the West Zone, the Nevada Coordinate System of 1927 or the Nevada Coordinate System of 1983 must be named, and in any land description in which it is used it must be designated, the "Nevada Coordinate System of 1927, West Zone" or the "Nevada Coordinate System of 1983, West Zone."
