# NRS 116B.325 Description of units.
A description of the residential units and the hotel unit which sets forth the name of the condominium hotel, the file number and book or other information to show where the declaration is recorded, the county in which the condominium hotel is located and the identifying number of the units is a legally sufficient description of those units and all rights, obligations and interests appurtenant to those units which were created by the declaration or bylaws.
