# NRS 81.620 Applicability of NRS 81.550
to 81.660, inclusive. The provisions of NRS 81.550 to 81.660, inclusive, apply to any private foundation whether it was created before or is created on or after October 1, 1991, if it is subject to the sections of the Internal Revenue Code set out in NRS 81.550 to 81.660, inclusive.
