# NRS 440.437 Death caused by sudden infant death syndrome: Report by State Registrar.
The State Registrar shall annually publish a report specifying the number of postmortem examinations performed, pursuant to NRS 440.435, where the cause or suspected cause of death was sudden infant death syndrome. Such report shall also specify the number of such cases in which the cause of death was determined by the coroner to be sudden infant death syndrome.
